

\# AI Gaming Clip Generator



A local Python project exploring AI-assisted video processing

for converting long gaming recordings into vertical short-form

content for YouTube Shorts and Instagram Reels.



\## Features



\- Speech transcription using OpenAI Whisper

\- GPU-accelerated processing with PyTorch and CUDA

\- Video processing using OpenCV and FFmpeg

\- Short-form video rendering experiments

\- Caption and subtitle styling

\- Facecam-aware video composition experiments



\## Tech Stack



\- Python 3.11

\- OpenAI Whisper

\- PyTorch

\- CUDA

\- OpenCV

\- MoviePy

\- FFmpeg

\- ASS subtitles



\## Project Status



Experimental project under active development.



The current implementation is a starting point. Highlight

selection quality, pipeline reliability and usability remain

areas for improvement.



\## Hardware



Developed and tested on a Windows laptop with an NVIDIA RTX

5060 Laptop GPU (8 GB VRAM).



GPU acceleration depends on compatible drivers and software

versions.
